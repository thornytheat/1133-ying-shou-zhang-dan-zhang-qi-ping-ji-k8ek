# 应收账单业务契约

历史窗口按特征日切分。2026 年 6 月 1 日前的已成熟户月拟合尺度与逻辑回归。后续已成熟户月用于保序拟合，校准统计属于校准集拟合内诊断。2026 年 9 月 1 日后才成熟的标签排除。

账面金额与回款使用十进制解析并转换为整数分。账单以最新已入账版本为准，冲销和同版冲突保留证据。发生金额超过有效欠款时按到账时间顺序抵扣，超出放入暂挂。账龄按未到期、1–30、31–60、61 日以上分组。统计到期日包含于未到期一组。

评分输入为未结比例、逾期未结比例、最久逾期日、账单账龄、账单笔数与未结金额的 `log1p`。方差先减均值再求平方均值。L2 惩罚不施加给截距。保序校准按得分合并逆序相邻区间，空正类时 AP 返回空值。同分样本以一个整体计入 PR 梯级。

推理若超出训练包络，按各维越界量除训练尺度计算欧氏距离，超过 3 暂停给出概率。复核顺序为分布外优先，再按逾期余额、总未结余额和得分排序。人工复核名额按户登记。复盘同时给出带半计数平滑的 PSI 与逐笔账面等式。

## 坏账准备清单

准备清单在关账时点按账单拆账，逐户列出、逐户与账面未结对账。同一笔未结金额只进入一个归口，五个归口互斥且合计等于该户账面未结：

- 单户核证：已逾期超过核证门槛（默认 60 天）的账单，按核证比例计提。
- 组合评分：其余已评分账单，按该户逾期概率计提。
- 待确认版本：该账单在关账时点后另有新版本，金额不计提。
- 待入账回单：该账单存在已到账但截点后入账的回单，仅暂扣回单金额不计提。
- 待复核：该户超出评分支持，不作估算，只列待复核。

正式准备只来自单户核证与组合评分两侧，二者按账单分段，不会对同一笔敞口重复计提，也不会只取一边而漏掉另一边。待确认版本、待入账回单与待复核金额不进入正式准备。新版本与待入账回单按账单归口，早于账龄判断；同一户其余已核证账单仍按各自归口计提。

计提按账单逐笔以分为单位四舍五入，单笔计提额不超过该笔敞口，因此逐户计提额可能低于两侧敞口之和。批次号由关账时点、账单、回款、凭证与评分的完整内容生成。正式台账按批次号登记，同一批次重跑只登记一次，逐户与合计都不重复增加；同一批次号对应不同清单时拒绝入账。


## 环节分组诊断

每个环节公开分组、风险方向与阈值、有效观测数、缺测数和命中的凭证。只有有限数值计入诊断，等于阈值的记录保持正常。相关证据计数与明细逐项守恒。诊断随 API 和证据导出提供。
